# こねくと Frontend

React + Vite。`docs/api.md` のMVP API契約v1に従います。Backend側のファイルは変更しません。

## 起動

Node.js 22.12以降、pnpm 11で `frontend/` に移動し、次を実行します。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

http://127.0.0.1:5173 を開きます。`pnpm build` で本番ビルド、`pnpm test` でMockの状態更新を検証します。

## Mockと実API

初期状態はMock。画面に「デモモード」と表示され、外部へのメッセージ送信はありません。サンプル会話、お気に入り、リマインダー、返信はlocalStorageの `konekuto-demo-v1` に保存されます。書き込み不可の場合はエラーを表示します。デモを初期化する場合はこのキーを削除してください。

実Backendを使う場合は `frontend/.env.local` を作成します。

```env
VITE_USE_MOCK=false
```

Viteを再起動すると `/api` を `http://127.0.0.1:3000` へ転送します。別ポートの場合は `API_PROXY_TARGET=http://127.0.0.1:別ポート pnpm dev` を指定します。実APIの失敗時にMockへ自動切り替えしません。

本番では `dist/` を配信し、同一オリジンの `/api` をBackendへ転送してください。開発プロキシはビルドに含まれません。VITE_変数にTokenやSecretを設定しないでください。

## 確認する操作

- LINEとSlackの一覧、名前検索、すべて・未返信・後で返信・お気に入りフィルタ。
- 人物を開いて履歴とスタンプを表示。本文はHTMLとして描画しません。
- 返信成功時だけ入力が消えます。失敗・結果不明なら入力を残し、自動再送しません。
- お気に入りの登録・解除、リマインダー設定・取消、再読み込み後の保存。
- 期限超過の強調。ブラウザ通知や外部通知は実装しません。
- 幅650px以下では一覧と会話が切り替わります。
- Backend結合時は空一覧、404、接続失敗、送信失敗、送信結果不明を確認してください。

5秒間隔で一覧と選択中の履歴を再取得します。人物ごとの下書きを保持し、別会話の遅延レスポンスは表示しません。Reminderはダイアログを開いた時点のMessage IDを送ります。
